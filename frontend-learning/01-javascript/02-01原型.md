# JavaScript 原型

## 一句话总结

原型是 JS 实现继承的机制——对象可以通过原型链访问其他对象的属性和方法，实现代码复用。

---

## 核心概念

### 1. 什么是原型？

每个对象都有一个内部链接，指向另一个对象，这个对象就是**原型**。原型对象也有自己的原型，层层向上，直到 `null`，这就是**原型链**。

```
myObj → MyProto → Object.prototype → null
```

### 2. 两个关键属性

| 属性 | 说明 |
|---|---|
| `__proto__` | 对象的原型（访问原型链用） |
| `prototype` | 构造函数的原型对象（创建实例用） |

```javascript
function Person(name) {
    this.name = name;
}
Person.prototype.sayHello = function() {
    console.log(`Hello, I'm ${this.name}`);
};

let peng = new Person("Peng");

// peng 的原型链
peng.__proto__ === Person.prototype        // true
Person.prototype.__proto__ === Object.prototype  // true
Object.prototype.__proto__ === null              // true
```

### 3. 原型链图解

```
peng (实例)
  │
  ├── __proto__ → Person.prototype (构造函数的原型)
  │                  │
  │                  ├── sayHello()
  │                  │
  │                  └── __proto__ → Object.prototype
  │                                    │
  │                                    ├── toString()
  │                                    ├── valueOf()
  │                                    │
  │                                    └── __proto__ → null
  │
  └── name: "Peng" (自己的属性)
```

## 核心概念

### 1. 构造函数与 new 的过程

```javascript
function Person(name) {
    this.name = name;
}
Person.prototype.sayHello = function() {
    console.log(`Hello, I'm ${this.name}`);
};

let peng = new Person("Peng");
```

**`new` 关键字做了什么？**

1. 创建一个空对象 `{}`
2. 将空对象的 `__proto__` 指向构造函数的 `prototype`
3. 执行构造函数，将 `this` 指向空对象
4. 返回这个对象

```javascript
// new 的伪代码实现
function myNew(Constructor, ...args) {
    let obj = {};                          // 1. 创建空对象
    obj.__proto__ = Constructor.prototype; // 2. 连接原型
    Constructor.apply(obj, args);          // 3. 执行构造函数
    return obj;                            // 4. 返回对象
}
```

### 2. 原型的查找机制

```javascript
peng.sayHello();  // 调用方法
```

查找过程：

```
1. 在 peng 自身找 sayHello → 没有
2. 在 peng.__proto__（Person.prototype）找 → 找到了
3. 执行方法
```

```javascript
peng.toString();  // 调用方法
```

查找过程：

```
1. 在 peng 自身找 toString → 没有
2. 在 peng.__proto__（Person.prototype）找 → 没有
3. 在 Person.prototype.__proto__（Object.prototype）找 → 找到了
4. 执行方法
```

### 3. 属性遮蔽（Property Shadowing）

```javascript
peng.toString = function() {
    return "custom toString";
};

peng.toString();  // "custom toString" ← 使用自己的方法
```

查找过程：

```
1. 在 peng 自身找 toString → 找到了
2. 直接使用，不继续查找
```

**这就是属性遮蔽——实例属性会遮蔽原型上的同名属性。**

### 4. 原型的动态性

```javascript
function Person(name) {
    this.name = name;
}

let peng = new Person("Peng");

// 后添加的方法，实例也能访问
Person.prototype.sayGoodbye = function() {
    console.log(`Goodbye from ${this.name}`);
};

peng.sayGoodbye();  // "Goodbye from Peng" ← 可以访问
```

**因为原型是引用类型，修改原型会影响所有实例。**

### 5. hasOwnProperty vs in

```javascript
peng.name          // "Peng" ← 自己的属性
peng.sayHello();   // 方法 ← 原型上的属性

peng.hasOwnProperty("name");      // true ← 自己的属性
peng.hasOwnProperty("sayHello");  // false ← 原型上的属性

"name" in peng;      // true
"sayHello" in peng;  // true ← 不管是谁的属性，只要能找到就返回 true
```

| 方法 | 说明 |
|---|---|
| `hasOwnProperty()` | 只检查自己的属性 |
| `in` | 检查整个原型链 |

## 常见的原型继承模式

### 1. 原型链继承

```javascript
function Animal(name) {
    this.name = name;
}
Animal.prototype.speak = function() {
    console.log(`${this.name} makes a sound`);
};

function Dog(name) {
    this.name = name;
}
Dog.prototype = new Animal();  // 继承 Animal

let dog = new Dog("Rex");
dog.speak();  // "Rex makes a sound"
```

### 2. 组合继承

```javascript
function Animal(name) {
    this.name = name;
}
Animal.prototype.speak = function() {
    console.log(`${this.name} makes a sound`);
};

function Dog(name, breed) {
    Animal.call(this, name);  // 继承属性
    this.breed = breed;
}
Dog.prototype = Object.create(Animal.prototype);  // 继承方法
Dog.prototype.constructor = Dog;  // 修复 constructor
```

### 3. ES6 Class（语法糖）

```javascript
class Animal {
    constructor(name) {
        this.name = name;
    }
    speak() {
        console.log(`${this.name} makes a sound`);
    }
}

class Dog extends Animal {
    constructor(name, breed) {
        super(name);
        this.breed = breed;
    }
}

let dog = new Dog("Rex", "Labrador");
dog.speak();  // "Rex makes a sound"
```

**ES6 的 `class` 本质是原型继承的语法糖，底层还是用原型链实现的。**

## 动手验证

```javascript
// 测试 1：原型链
function Person(name) {
    this.name = name;
}
Person.prototype.sayHello = function() {
    return `Hello, I'm ${this.name}`;
};

let peng = new Person("Peng");

console.log(peng.__proto__ === Person.prototype);  // true
console.log(peng.hasOwnProperty("name"));          // true
console.log(peng.hasOwnProperty("sayHello"));      // false
console.log("sayHello" in peng);                   // true

// 测试 2：属性遮蔽
peng.sayHello = function() {
    return "Custom hello";
};
console.log(peng.sayHello());  // "Custom hello" ← 使用自己的方法
console.log(Person.prototype.sayHello());  // "Hello, I'm Peng" ← 原型上的方法没变

// 测试 3：继承
function Animal(name) {
    this.name = name;
}
Animal.prototype.speak = function() {
    return `${this.name} makes a sound`;
};

function Dog(name) {
    Animal.call(this, name);
}
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

let rex = new Dog("Rex");
console.log(rex.speak());  // "Rex makes a sound"
console.log(rex instanceof Dog);    // true
console.log(rex instanceof Animal); // true
```

## 容易混淆的地方

1. **`__proto__` vs `prototype`** — `__proto__` 是对象的原型，`prototype` 是构造函数的原型
2. **实例属性 vs 原型属性** — 实例属性用自己的，原型属性共享
3. **ES6 class 是语法糖** — 底层还是原型继承
4. **属性遮蔽** — 实例属性会遮蔽原型上的同名属性

---

## 实际开发中的应用

- **理解 Vue 的原型** — Vue 2 通过 `Vue.prototype` 添加全局方法（如 `$http`）
- **理解组件继承** — Vue 的 `extends` 和 `mixins` 底层都是原型链
- **手写框架** — 理解原型是理解 Vue、React 源码的基础
- **性能优化** — 方法放在原型上而不是实例上，可以节省内存
